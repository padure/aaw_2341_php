# AAW 2341 — Programare Server-Side în PHP

## Disciplina

- **Disciplina:** Asistență pentru programarea server-side a site-urilor web
- **Cod:** S.07.O.021
- **Specialitatea:** Administrarea aplicațiilor web

Repository-ul este utilizat pentru organizarea și păstrarea codului elaborat pe parcursul disciplinei.

Materialele sunt împărțite în două categorii:

- exemple și cod realizat în cadrul lecțiilor teoretice;
- lucrări de laborator realizate separat pentru fiecare grupă.
